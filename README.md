# Agrinho 2025

Bem-vindo ao projeto **Agrinho 2025**, uma iniciativa dedicada a promover o conhecimento, a inovação e a sustentabilidade no meio rural. Este projeto visa conectar o campo ao futuro sustentável, oferecendo informações, workshops e oportunidades de interação entre especialistas e agricultores.

## Estrutura do Projeto

O projeto é composto por um arquivo HTML principal (`index.html`) que serve como a página inicial do evento. Abaixo estão os principais componentes do projeto:

- **HTML**: Estrutura básica da página.
- **CSS**: Estilos personalizados para a página.
- **Bootstrap**: Framework CSS utilizado para estilização e responsividade.
- **Bootstrap Icons**: Ícones utilizados na interface.

## Funcionalidades

- **Navegação**: Um menu de navegação que permite acesso a diferentes seções do site, incluindo:
  - Página Inicial
  - Energia Rural
  - Acessibilidade à Água
  - Produção e Industrialização

- **Destaques do Evento**: Seção que apresenta os principais temas do evento, como:
  - Energia Sustentável
  - Acessibilidade à Água
  - Produção e Industrialização

- **Inscrição**: Formulário para que os interessados possam se inscrever no evento.
